## 使用说明

| 场景 | 怎么做 |
|---|---|
| **首次启动** | 复制「可粘贴区」全文投给新会话即可（本会话上下文不必带） |
| **接力续跑** | 上一会话在 T3 边界会把同一段文字打回来（只改最后一句为「从 `next_task = <task_id>` 继续」），原样粘贴到新会话 |
| **想让它一次少跑点** | 在末尾追加一行「本会话只跑到 S<n> 结束，然后按 §8.1 交接」 |
| **想改成本策略** | 改 ORCH §3.2 的预算或 §3.4 的护栏比例；本提示词只引用不复制，改一处即生效 |
| **换项目复用** | 用 `docs/ORCH-TEMPLATE-v1.0.md` 的 §A 适配程序实例化，再把本文件的槽位换掉 |

> **诚实边界**：本提示词能让流程**不因为等人而中断**，但没有任何单个会话能一次跑完 52 个任务。真正的「无人值守」= 状态文件 + 交接件 + 可重入提示词构成的**接力链**（ORCH §8.1/§8.2）。若运行时不具备自动开新会话的能力（T2），则每个阶段边界会打印一次续跑提示词（T3），需要你粘贴一次——这是当前技术条件下的最短人工介入。

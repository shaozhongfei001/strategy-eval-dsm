# S1-T03 digest — WeightProvenance / evidence_source

## §3.11.4 WeightProvenance（v1.1 由 AhpProvenance 扩展，向后兼容）[L1228-1245]
- [L1230] class WeightProvenance（伪类原文，本任务最核心依据）
- [L1231] kind: AHP_ONLY | AHP_ENTROPY_COMBINED | EXPERT_ONLY
- [L1232] ahp: 专家两两比较矩阵、λ_max、CI、RI、CR、专家人数、访谈日期、
- [L1233] （ahp 续）几何平均法与特征向量法两套权重及其最大差
- [L1234] entropy: 标定窗口期列表、各期熵权、中位数熵权、逐指标漂移 drift_j、
- [L1235] （entropy 续）命中 INACTIVE 回退的指标清单、被剔除期及原因
- [L1236] combine: α 值、α 来源（CALIBRATED | MANUAL）、α 标定报告引用、
- [L1237] （combine 续）逐指标四列对照表（AHP 值 / 熵权值 / 组合值 / 是否回退）、
- [L1238] （combine 续）H-1~H-5 校验结果
- [L1239] alpha_basis: CalibrationReport 整体（候选 α × 指标矩阵、α*、命中约束、
- [L1240] （alpha_basis 续）被排除 α 及原因、窗口期清单、run_id、seed）
- [L1241] whatif_run_id: 权重影响预演运行号；FROZEN 而缺此项 → 配置加载直接失败
- [L1242] approved_by / approved_date / effective_from / effective_to
- [L1244] 业务含义：回答「凭什么贡献度占 30%」= 完整推导链（AHP + CR + 熵权 + α 标定）+ 后果预演（whatif）+ 签字人

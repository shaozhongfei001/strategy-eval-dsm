 1642| ## 4.7 五个端到端示例（合成数据，重点看业务含义）
 1643| 
 1644| > 以下数值全部为**演示用合成数据**，权重与门槛均为 PLACEHOLDER；示例中的分数是为讲清机制而假定的。
 1645| 
 1646| ### E1 正常路径：有对照、达标、无超线 → 一级
 1647| 
 1648| - 输入：S-014，control_arrangement = CONCURRENT_CONTROL，eval_method = DID → **证据 B**；composite_absolute 假定 1.02，超过 L1 门槛；投诉率与触达频次均未超红线
 1649| - 输出：grade = **L1**，eligible_for_L1_library = **true**，池 = CARD|B，池内第 3 / 共 11
 1650| - 动作：纳入优质策略库、形成标准化模板、提炼客群规则与触达方式、优先配置营销资源、跨机构复制推广
 1651| - **业务含义**：这条策略**效果达标、有对照证据、没打扰客户**，所以可以当标杆往全行推
 1652| 
 1653| ### E2 高分但无对照 → 被证据门禁拦下（**最能体现设计价值的一例**）
 1654| 
 1655| - 输入：S-022「个人贷款额度提升短信」，转化率与收入都很漂亮，composite_absolute 假定 1.15（高于 L1 门槛）；但 control_arrangement = NONE，eval_method = OBSERVATIONAL_ONLY → **证据 C**；interpretation_limit 已填「无对照组，增量不可识别，结果含自然转化」
 1656| - 输出：grade = **L2**（reason_code = GR_EVIDENCE_GATE_L1），eligible_for_L1_library = **false**（PL_L1_GATE_EVIDENCE），池 = LOAN|**C**，只与其他 C 类策略排名
 1657| - **讲给业务方的一句话**：这条策略数据很好看，但**我们无法证明是它带来的效果** —— 提额短信发给的本来就是额度使用率高、有借款意愿的人，他们不收到短信也可能提额。所以它可以继续跑、继续监测，但**不能当标杆全行推广**，否则等于把自然转化当成策略功劳，把资源押到一个未被证明的打法上
 1658| - 补充：如果连 interpretation_limit 都没填 → 证据降为 **D** → **NOT_ASSESSED，根本不出分**，台账单独计数
 1659| 
 1660| ### E3 业绩很好但打扰超限 → 强制四级（非补偿）
 1661| 
 1662| - 输入：S-031「财富客户理财产品推荐」，贡献度达成率 1.6、效益度 1.4，composite_absolute 假定 1.42；但 CONTACT_FREQ_PER_30D = 6，超 HARD 红线阈值 4，且无豁免审批留痕
 1663| - 输出：redline_pass = **false**，grade = **L4（强制）**，reason = REDLINE_CONTACT_FREQ_EXCEEDED；composite_absolute = 1.42 **照样算出来但不生效**
 1664| - **业务含义**：业绩再好，30 天里打扰客户 6 次就是超限。**分数我们照算给你看（1.42，确实很高），但等级不由分数决定** —— 这就是「风险不能被业绩买回来」。若允许加权抵消，这条策略会因贡献度高被评为一级并全行推广，等于把骚扰客户当成成功经验复制出去
 1665| 
 1666| ### E4 没设目标值 → 最多三级（诚实降级）
 1667| 
 1668| - 输入：S-008「新客首绑卡礼遇」，六个维度中四个维度的指标**没有 target_value**，绝对轨覆盖率 0.42，低于 min_coverage
 1669| - 输出：grade = **L3（封顶）**，capped_flag = true，cap_reason = GRADE_CAPPED_NO_TARGET；composite_relative 仍给出（用于池内参考）
 1670| - **业务含义**：不是这条策略不好，是**我们无法判断它是否达标** —— 因为它没有目标值。相对分只能告诉我们它排第几，不能告诉我们它完成了任务。诊断报告会提示：**请为这四个维度的指标补设目标值并说明依据**，下期即可正常参评
 1671| - 价值：把「指标口径不完整」这个管理问题**变成看得见的等级上限**，从而推动口径治理，而不是用一个假装精确的分数掩盖过去
 1672| 
 1673| ### E5 压线策略 → 标注边界结论
 1674| 
 1675| - 输入：S-014 的 composite_absolute = 1.0200，L1 门槛假定 = 1.00；OAT +20% 扰动下掉到 L2
 1676| - 输出：stability_label = **NEAR_BOUNDARY**，flip_under_pct20 = true
 1677| - **业务含义**：这条策略**刚好压线**。把贡献度权重上调 20%，它就掉到二级。所以：①可以按一级管理，但报告标注边界结论；②**若要拿它做淘汰或问责依据，必须先复核门槛值与权重设定**
 1678| - 反向价值更大：若一条策略是 **UNSTABLE**（±10% 扰动就变级）且被评为四级要退出，报告会明确写「不得作为淘汰唯一依据」—— **这防止了用脆弱的分数去决定一条策略的生死**

# S1-T01 digest D — 中间模型（Frame 8 / PoolStats / ScoringContext）与输出模型字段

## AttainmentFrame（§3.5.1 [L923-933]）
- [L927] 签名：compute(facts: MetricFactFrame, metric_dict: MetricDict, config: AppConfig) -> AttainmentFrame
- [L928] 字段：逐（策略×指标）attainment、direction、target_source、has_target、capped_flag；逐策略 attainment_coverage（=有目标值指标数/签认指标数）
- [L930] 边界：目标值缺失→attainment=null（不得用均值代替）；target=0 且方向为负→safe_div 的 on_zero；actual<0→记 NEGATIVE_ACTUAL 并按 missing_rule 处理
- [L931] reason_code：NO_TARGET_VALUE、ATTAINMENT_CAPPED、NEGATIVE_ACTUAL
- [L932] 关键约束：本模块输出是分级门槛的唯一依据；grading 不得从 normalize 取值判等级（P-1 守护）

## NormalizedFrame（§3.5.2 [L935-945]）
- [L939] 签名：compute(facts, metric_dict, anchor_set: AnchorSetDoc, config) -> NormalizedFrame
- [L940] 支持方法（Literal）：min_max / z_score / rank_percentile（配置切换；归一化互换敏感性全跑）
- [L941] min_max 的 min/max 与 z_score 的 mean/sd 优先取自 anchor_set；锚定集失效→回退当期池内统计+标注 RANK_REVERSAL_RISK
- [L942] 标准化在池内进行（biz_domain × evidence_class），禁止跨池归一（P-6 与 G-02 守护）
- [L943] 边界：sd=0→INACTIVE 剔除并预警；池内样本数<min_pool_size→WARN+SMALL_POOL
- [L944] reason_code：INACTIVE_METRIC、RANK_REVERSAL_RISK、SMALL_POOL、ANCHOR_SET_STALE
- [L945] 约束：输出只用于排名与相对轨综合分，不得进入等级门槛判定
- 事实注记：SDD 未给 NormalizedFrame 逐字段清单；P-4 [L1428]（见 S1-T01e.md）提及其中 norm 值

## ScoreFrame（§3.5.3 [L947-956]）
- [L951] 签名：compose(attainment: AttainmentFrame, normalized: NormalizedFrame, weights: WeightVersionDoc, config) -> ScoreFrame
- [L952] 字段：composite_absolute、composite_relative、逐维度 dim_d（两轨各一套）、coverage、weight_version_id、operator
- [L953] operator（Literal）：LINEAR（默认）/ GEOMETRIC / NON_COMPENSATORY（接口保留，默认不启用）
- [L954] 权重重归一：指标被剔除（未签认/SUSPECT/INACTIVE）后在维度内重归一并记 WEIGHT_REALLOCATED；维度被清空则 W_d 置 0 后在维度层重归一
- [L955] INV-3：只读 FROZEN 权重，不得调用 diagnostics 或 weights_combine；权重版本 id 必须写入每一行 score_card

## GradeFrame（§3.5.4 [L958-968]）
- [L962] 签名：assign(scores: ScoreFrame, attain: AttainmentFrame, ev: EvidenceFrame, rl: RedlineFrame, prev: GradeFrame or None, rules: GradeRuleSet) -> GradeFrame
- [L964] 字段：grade ∈ {L1, L2, L3, L4, NOT_ASSESSED}；grade_reason_path（有序 reason_code 列表，可还原判定路径）；capped、cap_reason；action（各级应执行动作与期限）；usable_for_elimination
- [L965] 滞回参数：upgrade_consecutive_periods（原文默认 2）、demotion_immediate（原文默认 true）、红线单期即降
- [L966] version_id 变化→VERSION_BREAK，滞回状态重置，不做跨版本趋势比较
- [L967] reason_code：CAPPED_NO_TARGET、CAPPED_EVIDENCE_C、VERSION_BREAK、HYSTERESIS_HOLD、FORCED_BY_REDLINE
- [L968] 等级判定只看绝对轨；相对轨综合分只写披露列（P-1）

## EvidenceFrame（§3.6.1 [L972-982]）
- [L976] 签名：classify(design_cards: DesignCardFrame, facts: MetricFactFrame, config) -> EvidenceFrame
- [L977] 判定顺序（短路）：①设计卡缺失→D（NOT_ASSESSED）②randomized=true 且有对照组与事前成功判定（含显著性口径）→A ③准实验（DID/合成对照/分层匹配/时间断点，须写方法名与假设）→B ④仅观测→C ⑤C 类未写 interpretation_limit→降 D
- [L978] evidence_mode 默认=GATE_ONLY（证据不乘入分数，只做封顶、分池与一级库准入）；DISCOUNT 保留接口，启用须另立 ADR 并纳入敏感性扰动维度
- [L979] A 类保守性：success_criteria 自由文本用外置可审计关键词清单识别显著性口径；清单外一律保守不认 A；禁止用模型猜测（RK-4）
- [L980] 字段：evidence_class、evidence_reason、evidence_source（CARD_ONLY / CEL_ESTIMATED）、control_group_id、interpretation_limit
- [L981] 与 CEL 接口单向：CEL→T4→evidence.py，evidence.py 不得反向调用 CEL
- [L982] reason_code：EVIDENCE_CARD_MISSING、EVIDENCE_C_NO_LIMIT、EVIDENCE_DOWNGRADED_PARTIAL

## RedlineFrame（§3.6.2 [L984-994]）
- [L988] 签名：evaluate(facts, redlines: RedlineSet, waivers: WaiverSet) -> RedlineFrame
- [L989] HARD：命中且无有效豁免→forced_grade（原文默认 L4）；综合分照算并披露但不生效
- [L990] SOFT：命中→独立扣减（等级判定之外单列），不进加权
- [L991] 豁免：必须有 approval_id + 有效期 + 豁免范围；过期或范围不符→视为无豁免并记 WAIVER_INVALID
- [L992] 红线指标不参与熵权组合（D2 约束①）；红线判定与权重完全无关，whatif 中 redline_delta 非空即配置错误信号
- [L993] reason_code：REDLINE_HARD_<code>、REDLINE_SOFT_<code>、WAIVER_INVALID、WAIVER_EXPIRED
- [L994] 阈值来源：redlines.yaml 必须引用行内既有制度文号；不得由模型方拟定（R4）

## §4.6.1 score_card 关键段 [L1608-1626] 段|业务含义
- [L1612] 版本四元组（weight_version_id / dict_version / anchor_set_id / run_id）：这个分数是哪套规则算出来的，申诉与复跑第一入口
- [L1613] per_metric（实际值/目标值/达成率三列并排）：全部保留、不做黑箱
- [L1614] per_dim（各维度达成率、相对分、coverage、W）：coverage 低必须显式暴露
- [L1615] composite_absolute：主分数，用于定级（加权整体目标达成率）；[L1616] composite_relative：辅分数，仅同池排名，不能判达标
- [L1617] evidence_class + evidence_reason：分数可信度及原因
- [L1618] interpretation_limit：C 类必填；未填→降 D 不出分
- [L1619] redline_pass + redline_flags：踩线时分数照算但不生效，等级强制
- [L1620] grade + grade_reason_codes：最终等级与判定路径（按判定顺序记录）
- [L1621] capped_flag + cap_reason（无目标值/证据 C 封顶）；[L1622] ranking_pool + rank_in_pool + pool_size（池=业务领域×证据等级）
- [L1623] eligible_for_L1_library + l1_gate_reasons；[L1624] stability_label + flip_under_pct10/20（NEAR_BOUNDARY=边界结论不得作淘汰唯一依据）
- [L1625] usable_for_elimination（受 flip_rate 与方法分歧双重约束）
- [L1626] CEL-0 增量三列 + value_captured：首版恒为空，报告显式写「本期末接入增量估计」，不得静默留白

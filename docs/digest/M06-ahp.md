  503| ### 2.4.1 AHP：它其实是「最入分」的一个
  504| 
  505| AHP 不在评分时运行，但**评分时用的每一个权重都是它的产物**。说它「不入分」只是说它不在评分流水线上；从因果链看，它对分数的影响比任何在线方法都大。

  507|     dsm ahp build --matrices config/ahp_matrices.yaml --out .tmp/ahp_result.yaml

  509| **算法（几何平均法为主，特征向量法为交叉验证）**：
  510| 
  511|     Step 1  读入两两比较矩阵 A = [a_ij]，a_ij 表示「维度 i 相对维度 j 的重要度」（1-9 标度）
  512|     Step 2  互反性校验: a_ij · a_ji = 1（1e-12 容差）；不满足 → 抛 MatrixNotReciprocalError
  513|     Step 3  多专家聚合: a_ij(聚合) = ( Π_k a_ij(k) ) ^ (1/K)     # 几何平均，聚合后仍满足互反性
  514|     Step 4  几何平均法求权重: w_i = ( Π_j a_ij ) ^ (1/n) ，随后归一 Σ w_i = 1
  515|     Step 5  特征向量法交叉验证: 解 A·w = λ_max·w；两法权重差 ≤ 1e-6，否则记 METHOD_MISMATCH
  516|     Step 6  一致性检验:
  517|                 CI = (λ_max − n) / (n − 1)
  518|                 CR = CI / RI(n)          # RI 为随机一致性指标查表值
  519|             CR ≥ 0.1 → **拒绝产出权重草稿**，并输出最不一致的前 5 对判断（供专家重填）
  520|     Step 7  产出 AhpResult（维度层 W_d(AHP) + 指标层 w_j(AHP)），status 只能是 DRAFT
  521| 
  522| **治理边界（机器强制）**：工具产出的 status 只能是 DRAFT；写 FROZEN → 抛错（T-AHP-06）。签认是人的动作，代码不得代劳。
